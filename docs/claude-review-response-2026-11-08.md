## التنفيذ بالترتيب

1. **البند 4:** تحويل ملفات IBM Plex الستة إلى WOFF2 كاملة دون اختزال الحروف. تطابقت خرائط Unicode، وترتيب الرموز، والقياسات، وأشكال كل الرموز، وجداول GSUB/GPOS/GDEF. انخفض حجم الملفات من 595,312 إلى 426,056 بايت (28.4%). تحدّثت CSS والتحميل المسبق. حُذفت ملفات WOFF السابقة وTajawal غير المستخدم، وبقيت تراخيص IBM Plex. التفاصيل في `ibm-plex-woff2-verification.json`.
2. **البند 6:** إخراج `dist/server/index.js` من Git وإضافته إلى `.gitignore`. يبقى `scripts/build-worker.mjs` المصدر الذي يولده، وتُضمّن النتيجة في أرشيف النشر. لا يُعاد كتابة التاريخ القديم للمستودع؛ حذف الملف يمنع إضافات مستقبلية ولا يمحو النسخ التاريخية.
3. **البند 7:** تطبيع نهايات الأسطر وإضافة `.gitattributes`، وتطبيع مدخلات بصمة الموارد، وترتيب الموارد بترتيب ثابت. إضافة `verify-build-stability.mjs` الذي يعيد البناء مرتين، ويقارن الناتج المولد، ويفشل إذا تغيّر أي ملف متعقب عن HEAD. تُحدّث HTML المعتمدة وتُزامن بعد التحقق.
4. **البند 2:** إعداد سياسة التخزين واختبار فرعي الخاص والعام. بقي `publicCachingEnabled: false`، ولا تتغير سياسة الموقع الخاص الحالية. الاستثناء المقصود عن اقتراح التقرير: الملفات غير المرقمة تأخذ ساعة مع إعادة تحقق عند الإطلاق، ولا تأخذ immutable عامًا كي لا تبقى الشعارات أو الخطوط القديمة عند تغيير نفس اسم الملف.
